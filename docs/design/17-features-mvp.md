# 17 功能清单与 MVP 需求规格

> 分级：**MVP**（Windows 和 macOS 首个公开版本）/ **v1**（MVP 之后 1–2 个版本）/ **以后**。每个功能都写了验收标准（AC），并标注它占用的性能预算（PB，见 17.3 节）。验收用的测试项编号对应 [bench/TEST_PLAN.md](bench/TEST_PLAN.md) 和 12 章。所有阈值都是【推断】起点，首次真机实测后再修订。

## 17.3 性能预算（PB）
测量方法见 12 章 12.1：增量 = 壁纸运行时减去静态壁纸基线，取 10 分钟平均。硬件基线是 Intel iGPU 笔记本（Win）和 M1（mac）。

| 预算 | CPU（核） | GPU | 内存 | 依据 |
|---|---|---|---|---|
| PB-idle（控制进程和探针，不含渲染器；UI 关闭时） | ≤ 0.002 | 0 | ≤ 60 MB | 【推断，目标】07 章 7.6、12 章 12.3 |
| PB-video（每块屏，4K30，硬解） | ≤ 0.03 | Video Decode 引擎占用和 3D 占用都要记录，3D ≤ 5%（iGPU） | mpv ≤ 150 MB | 【推断，目标】对照：软解要 0.51 核【实测】，OBS 硬解约 2%（3950X）【实测，第三方】。第 14 轮注：该 2% 是整机百分比，折算约 0.6 逻辑核【推断】，0.03 目前无同类实测支撑，W-T3 后修订 |
| PB-paused（L1，每块屏） | ≤ 0.005 | 约 0 | 不要求释放 | 【推断】 |
| PB-battery | 与 PB-paused 相同，或者 15fps 时为 PB-video × 0.5 | | | 【推断】解码负载大致与帧率成正比 |
| PB-web（每块屏，fps=30） | 与页面复杂度有关；宿主自身 ≤ 0.02，超过 0.5 核持续 60 s 就提示 | | 每屏 ≤ 300 MB（参考：box 上 WebKitGTK 是 442–445 MiB PSS，但那是软件 GL，偏高）【实测，仅作参考】 | 10 章 10.6 |
| PB-shader | GPU 帧时间 ≤ 4 ms（自动降分辨率） | | | 08 章 8.3 |

**MVP 发布门槛**：F-01 到 F-10 加上 F-15、F-16 的 AC 全部通过；PB-idle、PB-video、PB-paused 在 Intel iGPU 笔记本和 M1 两台机器上达标；TEST_PLAN 的 W-T1、W-T3、W-T6、W-T9、M1–M4 都有记录。
