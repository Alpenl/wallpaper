# 重写版 v1 验收单

这份清单是 `rewrite` 分支是否可以进入下一里程碑的唯一依据。

## 判定规则

- **通过**只有一种来源：在目标平台的真机上跑过，并留下下面要求的证据。
- 单元测试、交叉编译、假控制器截图、方法返回成功，都不算通过。
- 每项结果只能是：通过、失败、未测。环境受限记为未测，并写明缺什么。
- 代码改动后，受影响的项目回到未测。历史结果不继承。
- 真人看到的画面与工具结果冲突时，以真人看到的为准。

每条记录写明：commit、系统版本、设备、显示器配置、素材、日志或录屏位置。

## v1 范围

macOS 和 Windows；视频和静态图；每屏独立分配；暂停、电源、全屏遮挡、锁屏；托盘和设置窗口；本地导入和库；退出恢复原壁纸；最小诊断。

v1 不转码。系统解码不了的素材必须在导入时明确拒绝并说明原因。

## M1 单屏视频打通

两个平台都要逐项通过。Windows 需要对 Media Foundation 和 mpv 各跑一遍。

| ID | 场景 | 通过标准 | 证据 |
|---|---|---|---|
| M1-01 | 启动播放 | 视频出现在桌面图标下方，首帧前没有黑屏或闪烁 | 录屏 |
| M1-02 | 持续播放 | 连续 10 分钟画面在变化 | 状态文件 + 间隔截图 |
| M1-03 | 循环 | 多次循环，接缝处没有黑帧 | 录屏 |
| M1-04 | 确认机制 | 状态只有在平台证实画面在显示且播放位置前进后才变为 confirmed | 状态文件 |
| M1-05 | 损坏素材 | 明确失败并给出原因，不留下黑色表面，进程不残留 | 状态文件 + 进程列表 |
| M1-06 | 窗口交互 | 桌面图标可点击，普通窗口始终在壁纸上方 | 真人确认 |
| M1-07 | 退出 | 5 秒内退出，壁纸表面消失，桌面恢复，无残留子进程 | 脚本结果 + 真人确认 |
| M1-08 | 资源 | 播放 30 分钟，内存和句柄没有持续增长 | 采样记录 |
| M1-09 | Windows 后端选型 | 对比两条路径的循环、资源和画面质量，定案后删除另一条 | 对比记录 |

## M2 多屏与恢复

| ID | 场景 | 通过标准 |
|---|---|---|
| M2-01 | 双屏独立分配 | 每屏播放各自的壁纸，互不影响 |
| M2-02 | 混合 DPI | 每屏画面都铺满，没有偏移或模糊 |
| M2-03 | 稳定屏幕 ID | 重启或重新插拔后，分配回到正确的屏幕 |
| M2-04 | 热插拔 | 插入和拔出都不黑屏、不崩溃，分配正确 |
| M2-05 | 手动暂停 | 暂停和恢复立即生效，恢复后没有黑屏 |
| M2-06 | 全屏与遮挡 | 全屏或完全遮挡时暂停，离开后恢复且没有黑屏 |
| M2-07 | 锁屏 | 锁屏时不播放，解锁后恢复，短锁和长锁都测 |
| M2-08 | 睡眠唤醒 | 短睡和整夜睡眠后都能恢复 |
| M2-09 | 电源策略 | 电池和低电量策略按设置生效 |
| M2-10 | macOS Space | 切换 Space 和全屏 Space 后壁纸都在 |
| M2-11 | Explorer 重启 | Windows 上 Explorer 重启后壁纸自动恢复 |
| M2-12 | 渲染崩溃 | 杀掉渲染进程后按退避恢复，反复失败时进入明确的失败状态 |

## M3 库、导入与界面

| ID | 场景 | 通过标准 |
|---|---|---|
| M3-01 | 导入 | 单个和批量导入都可用，可取消，失败时说明原因 |
| M3-02 | 不支持的素材 | 导入时拒绝并说明原因，库里不留下半成品 |
| M3-03 | 库操作 | 搜索、删除、应用到某屏或全部屏幕都正确，删除有确认 |
| M3-04 | 三页界面 | 壁纸库、显示器、设置的中英文和深浅主题都可读 |
| M3-05 | 响应 | 导入或切换壁纸时界面不卡住 |
| M3-06 | 托盘 | 菜单每一项都可用，状态与实际一致 |
| M3-07 | 窗口驻留 | 关闭窗口后继续驻留，再次启动唤起已有实例 |
| M3-08 | 持久化 | 重启后设置和分配保留；配置损坏时有明确的恢复路径 |
| M3-09 | 旧数据导入 | 从旧版导入配置和库，可重试，不修改旧文件 |
| M3-10 | 诊断 | 导出的诊断包已脱敏，足够定位问题 |

## M4 发布与切换

| ID | 场景 | 通过标准 |
|---|---|---|
| M4-01 | 安装与卸载 | 两个平台都干净安装和卸载，升级保留数据 |
| M4-02 | 开机启动 | 开启后登录即启动，关闭后不再启动 |
| M4-03 | 退出恢复 | 正常退出、注销和被强杀后，桌面都不会停留在黑屏 |
| M4-04 | 长跑 | 连续运行 24 小时，含多次睡眠和锁屏，没有增长或失效 |
| M4-05 | 功耗 | 与同机静态壁纸基线对比，记录 CPU、GPU 和功耗 |
| M4-06 | 回退 | 切换 master 前保留可回退到旧版的路径 |
