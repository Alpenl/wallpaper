# Wallpaper v0.3.2

Test build for Windows. It fixes video wallpapers that would not resume and makes the interface denser.

## Changes

- Denser library, closer to Wallpaper Engine.
  - Margins are narrower, and the filters and navigation take less room, so more wallpapers fit on screen (about 7 columns at 1920×1080).
  - On Windows the title bar is hidden and the top bar no longer shows the icon, title or display selector. Drag the top bar to move the window.
  - The property panel runs the full height of the window, and the top and bottom bars are shorter.
- The bottom bar shows the confirmed playback state, such as playing, paused, "正在恢复…" or the pause reason, instead of the last import message.
- If a player stops responding, it restarts itself (at most twice) and the reason is written to the log.

## Fixes

- Windows: clicking 继续播放 after pausing now resumes video wallpapers. Before, the button changed but the video stayed paused.
  - Cause: the app read from and wrote to mpv and the Media Foundation helper over named pipes opened in synchronous mode. Once mpv was paused and silent, a waiting read blocked the resume command.
  - All of these pipes now use overlapped I/O, and writes to mpv time out after 2 seconds.
- Windows: closing a screen no longer times out (`close screen timed out`).
- mpv waits until a file has loaded before applying its pause state. Media Foundation keeps the pause state after a seek.
- Auto-optimisation is skipped silently when no encoder is available. Running it by hand still reports that ffmpeg is needed.

## Known limitations

The same as [v0.3.1](v0.3.1.md). Packages are unsigned and this is a prerelease.

## Validation

- Hosted CI on Linux, macOS and Windows, including new Windows-only pipe tests and race-detector runs.
- Not yet validated on real hardware: pause and resume on Windows, the hidden title bar and dragging, mixed DPI, D3D11, WebView2 and WASAPI.
