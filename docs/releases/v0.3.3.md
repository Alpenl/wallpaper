# Wallpaper v0.3.3

Test build for Windows. No new features: this release makes problems easier to diagnose and the code easier to maintain. Please use it to test pause/resume on real hardware and send a diagnostics export if anything goes wrong.

## Changes

- Version information. `wallpaperd -version`, the startup log, the About page and diagnostics now show the commit as well as the version. Untagged development builds report `dev` and are never offered updates.
- Updates compare versions strictly, so prerelease numbers compare as numbers (`rc.2` comes before `rc.10`). An update manifest in an unknown format is rejected before anything changes.
- Crash capture. If the app or one of its helper processes crashes, the crash is written to `logs/crash-*.log`. The 5 most recent crashes are kept.
- Helper logs. Error output from the mpv, Media Foundation, web and shader helpers goes to per-display logs. Each is capped at 2 MiB and keeps the previous run as `.1`.
- Playback logs. Every pause and resume records the display, wallpaper, backend, helper process and timing. Pause, seek and shutdown commands record whether a stall happened while sending the command or while waiting for the reply.
- Failures that used to be silent are now reported in the log and the interface: the log file failing to write, and settings failing to save or back up.
- The diagnostics export now includes crash and helper logs and which wallpaper and backend each display uses. Paths and personal fields are removed. The archive stays under 20 MiB, large logs contribute only their newest part, and `manifest.json` lists anything left out.

## Fixes

- Several tests that failed intermittently on slow CI machines now wait for the right condition instead of a fixed time.

## Known limitations

The same as [v0.3.1](v0.3.1.md). Packages are unsigned and this is a prerelease.

- To keep personal data out, plain-text logs in the diagnostics export (mpv, helper and crash logs) lose everything from the first path to the end of that line.

## Validation

- Hosted CI on Linux, macOS and Windows, including race-detector runs.
- Not yet validated on real hardware: pause and resume on Windows, crash files and helper logs from real processes, the Media Foundation backend, the hidden title bar and mixed DPI.
- If something goes wrong, export diagnostics from the 关于与诊断 page, or send the `%LOCALAPPDATA%\WallpaperApp\logs` folder.
