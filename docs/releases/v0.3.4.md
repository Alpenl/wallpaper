# Wallpaper v0.3.4

A test build for Windows that also fixes two problems found on macOS. It adds no features. The main changes make updates safer, make diagnostics more useful, and change the license.

Please use this build to test pause and resume on real Windows hardware. If anything goes wrong, send a diagnostics export.

## Changes

- **Updates survive interruption.** If an update is interrupted partway through, for example because the app crashes or power is lost, it is completed or rolled back the next time the app starts. Before, it could leave a mix of old and new files.
- **Diagnostics keep more of the error text.** The export now removes only the specific private values it knows about: your home folder, the app's data folders, your wallpapers' file paths and titles, and the mpv path. Before, everything from the first path to the end of the line was removed, so the error message after a path was lost.
- **The log records why the app quit**: from the tray, for an update, or because the system or another program asked it to.
- **Shutdown is quicker and cleaner.** Storage scans stop when the app quits, and the app no longer waits forever when a reply to a helper process stalls.

## Fixes

- macOS 27: the app crashed at startup because a display function moved to a different system framework. The app now looks for it in both places.
- macOS: quitting from the Dock, logging out, or sending a quit signal now waits for the app to save its state, as quitting from the tray already did. Before, the playback position was not saved, and quitting several times in a row could wrongly start safe mode.
- The diagnostics export no longer includes the empty crash file of the app that is doing the export.
- Fixed a test that occasionally failed on Windows CI.

## Known limitations

- The same as [v0.3.1](v0.3.1.md). Packages are unsigned, and this is a prerelease.
- On Windows, importing a wallpaper again can occasionally fail while the storage scan is still reading it. Trying again works.

## Validation

- Hosted CI on Linux, macOS and Windows, including runs with the race detector.
- Tested on macOS 27 hardware:
  - the app starts;
  - pause and resume work: covered, uncovered, and covered for 60 seconds;
  - after a quit signal, the state is saved and the shutdown is recorded as clean.
- Not yet tested on real hardware:
  - pause and resume on Windows;
  - the Media Foundation and WebView2 backends, whose code was restructured with the same behaviour;
  - the license page in the Windows installer;
  - quitting from the Dock or by logging out on macOS, which use the same path as the quit signal.
- If something goes wrong, export diagnostics from the 关于与诊断 page, or send the `%LOCALAPPDATA%\WallpaperApp\logs` folder.
