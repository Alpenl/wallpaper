# v0.3.0-mvp · 原生 UI 与本地 MVP 检查点

未签名预发布，不代表后续路线图全部完成，也不是 Windows/macOS 真机认证版本。

## 本版变化

- 以 `master` 的正式 Go/MyGo 应用为基础实现七页原生设置界面：壁纸库、显示器、播放、暂停与省电、通用、版本、关于与诊断。支持明暗主题、中英文、搜索筛选、导入/删除/转换队列及取消、错误反馈。
- 接通每屏设置、自动启动、配置保存、应用暂停规则、真实缓存统计与安全清理、诊断与受保护的更新/回滚入口。
- 补全 Windows/macOS 空间跨屏裁切与恢复，主屏单路音频、共享播放位置，分离 macOS Retina 逻辑尺寸和 backing 像素。
- 增加本地 UTC 周暂停/运行状态统计；没有能耗估算，也没有上传遥测。
- macOS 使用隔离的系统 AVFoundation 转码路径；补充 GIF、可选 ffmpeg、实际输出规范检查和原子发布。Windows Media Foundation 播放控制、失败回滚和宿主恢复更严格。
- 整理研究、设计、实现状态、验证台账和目标平台验收门槛。React 仍仅是独立 `ui` 分支中的设计稿，应用不包含 React、WebView 设置外壳或 React-Go 桥接。

## 下载与依赖

- Windows amd64 / arm64：按用户安装的 NSIS 安装器，**本版不捆绑 mpv**。默认视频后端需要自行安装可用的 mpv，并在“播放与性能”设置填写其可执行文件路径。缺少时视频播放不可用，不能把安装成功当成已可播放。可选原生 Media Foundation 后端有格式/能力限制，本轮没有实机验证。
- macOS amd64 / arm64：`.app.zip`，系统 AVFoundation 播放和转码不要求安装 ffmpeg；WebM/VP9 等不受系统路径支持的输入需要可选 ffmpeg。应用未签名、未公证，系统安全检查可能阻止启动。
- Linux amd64：`.tar.gz`，仅有限 X11 兼容，需要系统 mpv；不宣称 GNOME/Plasma/Wayland 完整支持。
- `SHA256SUMS`、`BUILD-INFO.txt`、`RELEASE-NOTES.txt` 用于核对下载和构建来源。没有设置生产更新公钥或签名服务，在线更新默认不可用。

不再默认下载可变的第三方 mpv nightly 并只打包其 exe；后续需要固定构建、完整许可证/对应源码材料和分发方案后再恢复捆绑。已有 0.2.x 安装可能仍留下旧 mpv，应自行确认路径和版本。

## 已验证和未验证

本地原生检查点已通过 27 个根模块包的测试（23 个含测试）、race、vet（保留项目既有 `-unsafeptr=false`）、五目标交叉编译、更新/回滚端到端测试、原生软件渲染 UI 交互测试及文档链接检查。真实 ffmpeg 输出和 GIF 边界测试已运行。

发布流水线在当前发布提交上重新执行根测试/race/vet、文档检查、更新端到端测试、五目标构建和包校验，通过后才创建 tag/发布；准确结果以对应 GitHub Actions 运行记录为准。交叉编译、离屏绘制不证明真机运行。

未验证：Windows/macOS 真机桌面嵌入、COM/Objective-C ABI、显卡/硬解、休眠与唤醒、平台自动启动、性能预算，以及签名/公证；Linux 实际桌面测试也不能由本次编译代替。新增 macOS AVFoundation 集成用例需在 macOS 主机另行运行。

## 尚未完成的后续范围

Web 壁纸、Shader 引擎、在线画廊/创意工坊、云同步与相关认证/内容信任仍未实现；它们不因出现于设计或研究文档而成为本版能力。壁纸鼠标输入、完整 Wayland 支持、商店发行与锁屏集成也不在本版承诺内。详见仓库中的 `docs/IMPLEMENTATION_STATUS.md` 和 `docs/VALIDATION.md`。
